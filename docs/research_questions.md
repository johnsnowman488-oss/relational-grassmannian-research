# Research questions

## Central question

Can evolving relational organisation, conditioned by accumulated temporal memory, be represented usefully through fixed-rank Grassmannian states?

## Questions separated by evidence stage

1. **History dependence:** does earlier history contain predictive information beyond the current observable state?
2. **Memory representation:** do fixed SOE channels retain that information on held-out sequences, and how do they compare with first-, second-, and third-order Markov baselines?
3. **Relational contribution:** does explicit typed relational structure add value beyond state plus SOE memory?
4. **Geometric contribution:** does a Grassmannian representation add measurable value beyond fixed-subspace, evolving-vector, and other non-geometric representations?
5. **Coupling:** after independent contributions are understood, does coupling relational structure and memory into a geometric state add value beyond the strongest individual component?

## Null and negative outcomes

A higher-order Markov model may match SOE performance. A relational layer may add no measurable information. Grassmannian geometry may add no value. These are valid results and should change the research direction rather than be explained away.

No novelty, superiority, or performance claim follows from E00 correctness tests.
